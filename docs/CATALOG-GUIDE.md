# מדריך: עדכון הקטלוג בכל המכשירים

המדריך מיועד למי שמעולם לא עבד עם Git או עם GitHub. כל הפעולות נעשות מתוך האפליקציה, בעמוד **קטלוג**.

## איך זה עובד

- הקטלוג (מוצרים, מחירים, קטגוריות וחבילות) נשמר באתר **מוצפן בסיסמה**. מי שאין לו את הסיסמה לא יכול לראות
  את המחירים, גם אם ימצא את הקובץ.
- כשמפרסמים קטלוג, כל מכשיר שפותח את האפליקציה מקבל אותו אוטומטית תוך כ-2 דקות.
- כל מכשיר חדש מבקש את סיסמת הקטלוג **פעם אחת בלבד**.

## הגדרה ראשונה (פעם אחת, כ-5 דקות)

במכשיר שממנו תעדכנו את הקטלוג (למשל המחשב במשרד):

1. פתחו את האפליקציה ועברו לעמוד **קטלוג**.
2. לחצו **הגדרות פרסום**.
3. **סיסמת הקטלוג**: בחרו סיסמה של 10 תווים או יותר (למשל כמה מילים יחד) ושמרו אותה במקום בטוח. את אותה
   סיסמה תמסרו לעובדים.
4. **מפתח גישה ל-GitHub**: פתחו את ההסבר "איך יוצרים מפתח גישה" בחלון ההגדרות ובצעו את 6 השלבים שבו. בקצרה:
   - היכנסו ל-GitHub ופתחו את
     [דף יצירת המפתח](https://github.com/settings/personal-access-tokens/new).
   - **Token name**: מחולל הצעות מחיר.
   - **Expiration**: התקופה הארוכה ביותר שאפשר.
   - **Repository access**: ‏Only select repositories, ואז המאגר **srfqm**.
   - **Permissions** ← **Repository permissions** ← **Contents**: ‏**Read and write**.
   - **Generate token**: מעתיקים את המפתח (מתחיל ב-`github_pat_`) ומדביקים באפליקציה.
5. לחצו **בדיקת חיבור**. אמורה להופיע ההודעה "החיבור ל-GitHub תקין".
6. לחצו **שמירה**.

המפתח והסיסמה נשמרים רק בדפדפן של אותו מכשיר.

## עדכון הקטלוג באקסל (בכל פעם)

1. בעמוד **קטלוג** לחצו **ייצוא לאקסל**. יורד קובץ Excel עם כל הקטלוג.
2. פתחו את הקובץ ב-Excel וערכו:
   - **לשונית "מוצרים"**: כל שורה היא מוצר. אפשר לשנות שם, תיאור, מחיר וקטגוריה.
   - **מוצר חדש**: מוסיפים שורה ומשאירים את עמודת "מזהה" ריקה.
   - **מחיקת מוצר**: מוחקים את כל השורה.
   - **קטגוריה חדשה**: כותבים שם קטגוריה חדש בעמודה "קטגוריה". היא תיווצר אוטומטית.
   - **לשונית "קטגוריות"**: סדר השורות קובע את סדר הקבוצות בהצעת המחיר. אפשר לשנות כאן שם של קטגוריה.
   - **לא משנים ולא מעתיקים את עמודת "מזהה"**. היא מקשרת כל שורה למוצר הקיים.
   - מחירים כותבים כמספר בלבד, בלי ₪.
3. שמרו את הקובץ (בפורמט הרגיל של Excel, ‎.xlsx).
4. באפליקציה לחצו **ייבוא מאקסל** ובחרו את הקובץ.
5. תוצג רשימת השינויים: מוצרים חדשים, מוצרים שעודכנו, מוצרים שיימחקו וקטגוריות. אם הכול נכון, לחצו
   **עדכון הקטלוג**.
   - אם יש שגיאה בקובץ (למשל מחיר שאינו מספר), יופיע מספר השורה. מתקנים באקסל ומייבאים שוב.
6. לחצו **פרסום לאתר**. תוך כ-2 דקות כל המכשירים יקבלו את הקטלוג החדש.

אפשר גם לערוך מוצרים וחבילות ישירות בעמוד הקטלוג, בלי אקסל, ואחר כך ללחוץ **פרסום לאתר**.

## מכשיר חדש או מכשיר של עובד

פותחים את האפליקציה. מופיע פס צהוב: "יש קטלוג מעודכן באתר". מזינים את סיסמת הקטלוג ולוחצים **טעינה**. מעכשיו
המכשיר יתעדכן לבד.

## בלי מפתח GitHub (פרסום ידני)

אם לא הוגדר מפתח גישה, לחיצה על **פרסום לאתר** מורידה קובץ בשם `catalog.enc.json` ופותחת הדרכה:

1. פותחים את [דף ההעלאה ב-GitHub](https://github.com/AssafHaft/srfqm/upload/main/public) (מחוברים לחשבון).
2. גוררים את הקובץ לחלון.
3. לוחצים על הכפתור הירוק **Commit changes**.
4. חוזרים לאפליקציה ולוחצים **סיימתי להעלות**.

## בעיות נפוצות

| מה קרה | מה עושים |
|---|---|
| "מפתח הגישה אינו תקין או שפג תוקפו" | יוצרים מפתח חדש (שלב 4 בהגדרה הראשונה) ומדביקים בהגדרות הפרסום. |
| "למפתח הגישה אין הרשאת כתיבה" | ביצירת המפתח לא נבחר המאגר srfqm, או ש-Contents לא הוגדר כ-Read and write. יוצרים מפתח חדש. |
| פרסמתי, אבל מכשיר אחר לא מתעדכן | ממתינים 2–3 דקות וסוגרים ופותחים את האפליקציה מחדש. אפשר לבדוק בדף [Actions](https://github.com/AssafHaft/srfqm/actions) שהעדכון האחרון מסומן ב-✓ ירוק. |
| שכחתי את הסיסמה | בוחרים סיסמה חדשה בהגדרות הפרסום, לוחצים **פרסום לאתר**, ומוסרים לעובדים את הסיסמה החדשה. |
| "באתר יש קטלוג חדש יותר, אבל במכשיר הזה יש שינויים שלא פורסמו" | מישהו פרסם ממכשיר אחר. **טעינה מהאתר** מקבלת את הגרסה שלו. **השארת הקטלוג שלי** ואחר כך **פרסום לאתר** מחליפה אותה בגרסה שלכם. |
