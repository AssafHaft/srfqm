# מדריך: סנכרון הצעות מחיר בין מכשירים

אחרי ההגדרה, כל הצעה שנשמרת במחשב מופיעה בטלפון, ולהפך, תוך שנייה. כך גם אצל העובדים. ההצעות נשמרות
ב-Firebase, מסד הנתונים של Google, בחינם. רק מי שבעל העסק אישר יכול לראות אותן.

## הגדרה ראשונה – בעל העסק בלבד (פעם אחת, כ-15 דקות)

באפליקציה עוברים ל**הגדרות** ← **סנכרון הצעות בין מכשירים** ← **הגדרת סנכרון (פעם אחת)**. החלון שנפתח מסביר כל
שלב. בקצרה:

1. **יצירת פרויקט**: ב-[Firebase Console](https://console.firebase.google.com/), מתחברים עם חשבון Google
   ולוחצים **Create a project**. שם הפרויקט, למשל: srfpark-quotes. את Google Analytics אפשר לכבות.
2. **כניסה עם אימייל**:
   - **Build** ← **Authentication** ← **Get started** ← **Email/Password** ← **Enable** ← **Save**.
   - בלשונית **Settings** ← **Authorized domains** ← **Add domain** מוסיפים את `assafhaft.github.io`.
3. **מסד נתונים**: **Build** ← **Firestore Database** ← **Create database**. מיקום: `eur3 (Europe)`, ואז
   **Start in production mode**.
4. **הרשאות**: באפליקציה כותבים את האימייל של בעל העסק ולוחצים **העתקת הכללים**. ב-Firestore, בלשונית
   **Rules**, מוחקים את הטקסט הקיים, מדביקים את הכללים ולוחצים **Publish**.
5. **חיבור האפליקציה**: בגלגל השיניים ← **Project settings** ← **Your apps**, לוחצים על הסמל `</>`, נותנים שם
   ולוחצים **Register app**. מעתיקים את כל קטע הקוד (`const firebaseConfig = {...}`) ומדביקים באפליקציה.
6. לוחצים **שמירה וחיבור**.
   - אם הוגדר מפתח GitHub (מעמוד הקטלוג), ההגדרה מתפרסמת אוטומטית לכל המכשירים.
   - אחרת יורד קובץ `cloud.json`, והאפליקציה מסבירה איך להעלות אותו ל-GitHub (גרירה ולחיצה על Commit changes).
7. **יצירת החשבון שלכם**: כותבים את **אותו אימייל** וסיסמה, ולוחצים **יצירת חשבון**. מגיע מייל אימות: לוחצים על
   הקישור שבו, חוזרים לאפליקציה ולוחצים **אימתתי**.

הצעות שכבר נוצרו במכשיר עולות לענן אוטומטית.

## הוספת עובד

1. בעל העסק: **הגדרות** ← **סנכרון הצעות** ← **משתמשים**. כותבים את האימייל של העובד ולוחצים **הוספה**.
2. העובד, במכשיר שלו: פותח את האפליקציה ← **הגדרות** ← כותב את האימייל שלו וסיסמה ← **יצירת חשבון**. לוחץ על
   הקישור במייל האימות ואז **אימתתי**.

כדי להסיר עובד לוחצים על סמל הפח ליד האימייל שלו. מאותו רגע הוא לא יכול לראות את ההצעות.

## מכשיר נוסף שלכם (למשל הטלפון)

פותחים את האפליקציה ← **הגדרות** ← כותבים אימייל וסיסמה ← **כניסה**. זהו.

## איך זה עובד

- בחלק העליון של המסך יש סימן ענן: **מסונכרן** (ירוק), **מסנכרן…**, או **לא מקוון**.
- **בלי אינטרנט** אפשר להמשיך לעבוד כרגיל. השינויים נשלחים כשהחיבור חוזר.
- **מספרי הצעות** משותפים לכל המכשירים, כך ששני מכשירים לא יקבלו אותו מספר.
- **הגדרות משותפות**: שיעור המע"מ, קידומת המספור, התוקף והערות ברירת המחדל משותפים לכל המכשירים.
- **עריכה בו-זמנית**: אם אותה הצעה נערכה בשני מכשירים באותו זמן, נשמרת העריכה האחרונה.
- **הקטלוג** ממשיך להתעדכן דרך **פרסום לאתר** בעמוד הקטלוג, כמו קודם.
